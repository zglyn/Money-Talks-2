# Simulated Issuer Ledger for the demo

We sell allocation software the Issuer would run inside its own system, but we do not have authority to move real Nicrron balances at the hackathon. CreditPool therefore treats a simulated Issuer Ledger as the money source of truth and states that plainly in the pitch.

The alternative — integrating live provider credits or key pooling — either breaks upstream terms or overclaims the demo. Sample data keeps us inside the event safety rule while still proving Return, Request, Reservation, apply, and Reconcile.
