## What to build

An Admin can configure one Program (budget, per-Team cap, expiry, returns allowed), register eligible Teams including a Program Pool Team, and Grant initial Credit on the simulated Issuer Ledger. Program console and Team wallet show balances and budget used vs remaining. No Credit moves yet beyond Grants.

## Acceptance criteria

- [ ] A Program exists with Program Rules fields and a Program Pool Team
- [ ] Eligible Teams can be registered under that Program
- [ ] Grants appear on the Issuer Ledger and Team wallet / Program console reflect summed balances
- [ ] Demo copy can state the Issuer Ledger is simulated (ADR-0001)

## Blocked by
